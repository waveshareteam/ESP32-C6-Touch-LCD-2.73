# 电池电压

[English](README.md) | [简体中文](README_ZH.md)

## 功能说明

在液晶上显示电池电压、12 位 ADC 原始值和采样平均方式。

## 硬件准备

ESP32-C6-Touch-LCD-2.73。开发板和 USB 数据线；测试电池电压时需要接入规格匹配的电池。

## 运行方法

1. 按照 [ESP-IDF 入门指南](../../../docs/getting-started-idf_ZH.md)配置环境，在 ESP-IDF v5.5.4 终端打开本项目。
2. 执行 `idf.py build`，再执行 `idf.py flash monitor`。
3. 将屏幕电压与电池端子处的万用表读数比较。

## 预期现象

电压和 ADC 卡片约每秒更新一次，每次平均 8 个样本；电压 = ADC × 3.3 / 4095 × 3。ADC 读取失败时显示 -- 和错误。

## 常见问题

本例为标称电压测量，并非电量百分比。仅接 USB 的读数不能判断电池是否接入或剩余容量，参考电压和分压电阻误差会影响精度。

引脚和板载用途请参阅[板级 IO 指南](../../../docs/board-io_ZH.md)。
