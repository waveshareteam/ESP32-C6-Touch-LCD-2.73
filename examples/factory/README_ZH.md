# ESP32-C6-Touch-LCD-2.73 出厂固件使用说明

[English](README.md) | [简体中文](README_ZH.md)

接通 USB 电源后，可以在 320 × 320 彩色触摸屏上体验屏幕测试、画板、天气、传感器、2048、电子徽章和电子时钟等 11 个应用。下面从第一次上电开始，介绍各个功能怎么用。

已经烧录出厂程序的开发板可以直接操作。需要恢复桌面时，先按[出厂固件说明](../../firmware/README_ZH.md)烧录合并 BIN；需要自行编译时，参阅本文最后一节。

## 1. 第一次拿到板子，先这样试

1. 使用 USB 数据线连接开发板与电脑或 USB 电源，等待桌面图标出现。
2. 打开 **Display Test（屏幕测试）**，观察红、绿、蓝、黄、白五种颜色是否正常；快速连续点击屏幕两下返回桌面。
3. 打开 **Touch Test（触摸测试）**，用单指在四角、边缘和中间画几条线，检查线条是否跟随手指。
4. 点击顶部中间的 **UI**，底部工具栏隐藏，按钮变成 **Exit**；再点击 **Exit** 返回桌面。
5. 桌面向左滑动，打开下一页的 **Button Test（按键测试）**，依次按下并松开 **BOOT、LEFT、RIGHT**。三项均显示 **PASS**，页面应显示 **3 / 3 buttons passed**。

先正常启动到桌面，再测试 BOOT。不要按住 BOOT 上电，以免进入下载模式。

### 应用在哪一页？

桌面每页最多显示 4 个图标，左右滑动切换页面，底部标记表示当前页。

| 页面 | 应用 |
| --- | --- |
| 第 1 页 | Display Test、Settings、Touch Test、GravityBall |
| 第 2 页 | Weather、Sensor、2048、Button Test |
| 第 3 页 | PinsTest、Badge、Watch |

### 想体验什么，需要准备什么？

| 功能 | 需要准备 |
| --- | --- |
| 屏幕、触摸、按键、重力球、2048、传感器读数 | 接通电源即可 |
| 网络校准北京时间、获取天气 | 能访问互联网的 2.4 GHz Wi-Fi |
| 上传电子徽章图片 | 带浏览器的手机或电脑，以及 JPG、PNG 或 WebP 图片；不需要互联网或 SD 卡 |
| 查看 SD 卡容量 | 可选的 FAT32 格式 microSD 卡 |
| 引脚电平测试 | 可选的万用表、逻辑分析仪或示波器 |

### 怎么返回桌面？

| 当前界面 | 返回方法 |
| --- | --- |
| Settings、Weather、Sensor、GravityBall、2048、Button Test | 点击左上角返回箭头；Settings 子页面先返回设置主页 |
| Display Test | 快速连续点击屏幕两下 |
| Touch Test | 点击顶部 **UI**，再点击变成的 **Exit** |
| Watch、PinsTest、徽章全屏图片 | 从屏幕最底部中间向上快速滑动 |
| Badge 上传页面 | 先点击板子上的 **Done** 结束上传页面，再返回桌面 |

底部上滑也可以退出多数应用；Display Test 和 Touch Test 请使用各自的退出操作。

## 2. 让板子连上 Wi-Fi

联网后，程序自动获取北京时间并写入 RTC，Weather 也可以更新天气。**仅支持 2.4 GHz Wi-Fi，不能连接 5 GHz 网络。**

### 使用手机或电脑配网

1. 板子上打开 **Settings → Wi-Fi setup**，等待热点名称和二维码出现，设置过程中先停留在此页面。
2. 扫描二维码，或在手机/电脑的 Wi-Fi 列表中连接 **C6-LCD-2.73-xxxxxx**。实际名称以屏幕为准，密码为 **12345678**。
3. 手机提示“此网络无法上网”时，选择**仍然连接 / 保持连接**。这是板子的本地配置热点，属于正常现象。
4. 在浏览器的**地址栏**输入 **http://192.168.4.1**。如果页面自动弹出，也可以直接使用。
5. 首页选择 **Wi-Fi Setup**，然后按下表操作。

| 网页上的名称 | 操作方法 |
| --- | --- |
| Scan nearby networks | 扫描附近网络 |
| Nearby networks | 选择自己的网络，也可以手动填写名称 |
| Network name (SSID) | 填写家中路由器或另一个手机热点的 Wi-Fi 名称 |
| Password | 填写该 Wi-Fi 的密码；开放网络留空 |
| Connect and Save | 提交设置，等待连接与保存结果 |

6. 显示 **Connected and saved** 表示连接成功，信息也已保存。以后重启会优先连接已保存的网络。
7. 需要上传徽章时，点击网页的 **Device home** 返回首页，再选 **Transfer Images**。不继续操作时，可在首页点击 **Disconnect & close hotspot** 关闭设备热点，再让手机连接回平时的网络。

**配网成功后，本地热点可以继续用于图片传输。** 不要照其他型号的说明等待它自动关闭，配网和徽章共用这个入口。长时间不操作后连接失效时，重新打开板子的 Wi-Fi setup 或徽章管理页面即可。

Settings 中的 **Wi-Fi scan** 只查看附近网络、信号与加密方式，不能通过点击网络名称输入密码；连接网络请使用 **Wi-Fi setup** 网页。

### 使用预设热点快速体验

尚未保存过网络时，可以在手机上开启名称为 **weather-wifi**、密码为 **12345678** 的 2.4 GHz 热点，并开启移动数据。板子启动后会尝试连接它。已有保存网络时，使用 Wi-Fi setup 更换即可。

### 时间什么时候更新？

开机先读取硬件 RTC 的已有时间，网络对时成功后，桌面、Watch 和 RTC 同步到北京时间（UTC+8）。**Wi-Fi 已连接不等于网络对时已完成**；首次对时可能需要等待，遇到请求重试时可能达到 1～2 分钟。

串口出现 `SNTP synced (UTC+8)` 表示收到网络时间，随后出现 `Beijing network time saved to RTC` 表示硬件 RTC 已更新。断网后时间继续走，不会恢复到联网前的旧日期。重新启动时，只要 RTC 供电没有中断，就能使用已保存的时间；RTC 丢失日历时，先使用初始日期，再等待联网校准。

## 3. 上传自己的电子徽章图片

电子徽章使用内置 Flash 保存 **6 张 320 × 320 图片**，不需要 SD 卡或互联网。图片保存在板子上，正常重启后仍可使用。

### 第一次上传

1. 打开 **Badge（电子徽章）**，等待初始化完成。首次使用可能需要准备存储，出现 **Preparing your badge...** 等提示时请等待。
2. 点击 **Add images**。已经有图片时，轻点图片呼出控制面板，再点 **Manage images**。
3. 按屏幕二维码或热点名称连接设备，密码为 **12345678**；浏览器打开 **http://192.168.4.1**，选择 **Transfer Images**。
4. 在 **Pictures** 中选择一个图片位置，通过 **Choose photo** 选择 JPG、PNG 或 WebP 图片。
5. 拖动预览图调整位置，用 **Zoom** 调整大小；未铺满的区域可用 **Background** 选择底色。板子是方屏，建议使用方图，或将主体放在预览图中间。
6. 点击 **Save To Selected Slot**，等待显示 **Picture saved and active on the device.**。保存过程中保持连接，不要关闭板子电源。
7. 上传其他图片时，先选择另一个位置再保存；使用已有位置会覆盖该位置原来的图片。
8. 完成后点击网页或板子上的 **Done**，回到徽章显示。

浏览器会将预览图处理为设备所需的尺寸和颜色格式，**不需要提前转为 RGB565、RGB666 或二进制文件**。图片会进行颜色量化以减少内存占用，渐变、细小文字和照片细节可能与原图存在差异，以保存前的网页预览为参考。

### 切换、管理和删除图片

| 操作 | 方法 |
| --- | --- |
| 下一张 / 上一张 | 在板子图片上向左 / 向右滑，或轻点图片后使用左右箭头 |
| 隐藏控制面板 | 点击 **Hide**，或再次轻点图片 |
| 指定当前显示图片 | 网页选择已有图片位置，再点 **Set Active** |
| 删除图片 | 网页选择已有图片位置，再点 **Delete**，只影响所选位置 |
| 网页列表没有更新 | 点击 **Refresh** |
| 返回桌面 | 结束上传页面后，从板子屏幕最底部中间向上快速滑动 |

Badge 是 Flash 电子徽章，当前出厂程序不包含 SD 卡相册 Photos，也不需要建立 `photo` 文件夹。

## 4. 其他应用怎么用

### Display Test：检查屏幕颜色

打开后按 **红 → 绿 → 蓝 → 黄 → 白** 循环，每种颜色约 **1 秒**。观察是否有固定亮点、暗点、异常色块或显示不均匀。**快速连续点击屏幕两下返回桌面**；未退出时缩短两次点击的间隔再试。

### Touch Test：检查触摸与绘画

用**单指**在空白画布上按住并滑动，检查线条是否连续、是否跟随触摸位置。底部可选黑、红、蓝、绿、橙色画笔，**2 / 5 / 9** 用于调整笔画粗细。

顶部 **UI** 第一次点击隐藏工具栏并变为 **Exit**，第二次点击返回桌面。当前没有 Clear 按钮，需要清空时退出后重新进入；绘画不保存到 Flash 或 SD 卡。

### GravityBall：倾斜控制重力球

打开后将板子平放并保持静止，等待底部校准进度结束，再缓慢向不同方向倾斜，观察小球移动。重新校准时，平放板子后按一下 **BOOT**，等待校准完成；左上角箭头退出。

### Weather：查看天气

连接可上网的 Wi-Fi 后打开 **Weather**，查看天气、温度、湿度等信息。右上角刷新图标可手动更新，服务也会约每 **5 分钟**自动更新。

默认城市为**深圳**，不会随设备位置自动变化。联网失败时可能保留上次数据，请留意更新时间和状态提示；修改城市的方法见最后一节。

### Sensor：同时查看三组传感器

| 屏幕区域 | 显示内容 |
| --- | --- |
| PCF85063A / RTC | 硬件 RTC 时间与日期 |
| QMI8658 / MOTION | X/Y/Z 加速度，单位 g；X/Y/Z 角速度，单位 deg/s |
| SHTC3 | 温度，单位 °C；相对湿度，单位 %RH |

RTC 和温湿度约每秒采样一次，运动数据更新更快。静止时加速度受重力影响，不会三个轴都为 0；角速度应接近 0。底部 **RTC OK / IMU OK / SHT OK** 表示对应读数正常，`--` 表示对应设备暂不可用。

Sensor 显示硬件 RTC 读数；Watch 和桌面使用从 RTC 恢复、再由网络校准的系统时间。网络时间写回 RTC 后，两者应基本一致。

### 2048：数字合并游戏

在棋盘内向上、下、左、右滑动，移动并合并相同数字，尝试得到 2048。**SCORE** 是当前得分，**BEST** 是本次运行中的最高分；**New Game** 重新开始，左上角箭头返回桌面。重启会清除内存中的游戏状态。

### Button Test：检查三个实体按键

依次按下并松开 **BOOT、LEFT、RIGHT**，观察对应卡片的 **PRESSED / RELEASED**、**Presses** 次数和 **PASS** 结果。三键都完成后显示 **3 / 3 buttons passed**；**Test again** 清空本轮结果。

按键保持按下时只算一次，松开后再次按下才累计下一次。请在这个页面测试按键，不要在 PinsTest 输出测试期间同时按 BOOT。

### PinsTest：检查引脚高低电平

此页面用于**输出电平测试**，不是万用表读数或外部输入电平检测。

| 测试区域 | 引脚 |
| --- | --- |
| GPIO，8 路 | GPIO9、GPIO3、GPIO15、GPIO23、GPIO13、GPIO12、GPIO22、GPIO21 |
| EXIO，11 路 | EXIO4～EXIO14 |

进入时显示 `--`，表示本轮尚未操作，**不表示引脚必然为低电平或高阻态**。首次点击输出高电平并显示 **H**，再次点击输出低电平并显示 **L**。可以用万用表或逻辑分析仪相对 GND 测量确认，顶部计数表示本轮已设为 H 的项目数量。

从屏幕最底部中间向上快速滑动退出。退出时 MCU 测试引脚恢复输入，EXIO 保留最后设置的电平。GPIO9 与 BOOT 共用，测试期间不要按住 BOOT，也不要将正在输出的引脚直接连接到其他输出端或电源。

### Watch：电子时钟

打开 **Watch** 查看大数字时钟、日期、星期和秒数。底部 **RTC clock** 表示时间从 RTC 恢复，**NTP synced** 表示本次运行已收到网络时间；断网后仍可能显示 NTP synced，这是时间来源提示，不代表 Wi-Fi 仍连接。

从屏幕最底部中间向上快速滑动返回。时钟页面与桌面共用全局时间，不需要每次进入时钟重新联网。

## 5. Settings：调亮度、查看网络和 SD 卡

设置主页可上下滚动，下面的项目没显示完整时向上滑动列表。

| 页面上的名称 | 使用方法 |
| --- | --- |
| Brightness | 拖动滑块调整背光，范围 10%～100%；完成调整后自动保存，下次启动继续使用 |
| Wi-Fi scan | 查看附近网络名称、信号强度与加密方式；**Scan again** 重新扫描，左右箭头翻页 |
| Wi-Fi setup | 显示热点和二维码，用手机浏览器配网或进入图片管理 |
| SD card | 查看识别状态、容量与可用空间；插入卡后点 **Refresh** 重新检测 |
| About | 查看固件、ESP-IDF 版本、显示尺寸、Flash、PSRAM 和设备 MAC 信息 |

SD 卡是可选项，未插卡时 **Unavailable** 不影响其他应用。建议使用 FAT32；如需格式化，请先备份卡内数据。容量按十进制 GB 显示，可能与电脑或包装的数字有差异。本机无 PSRAM，About 显示 0 MB 是正常现象。

## 6. 遇到问题，先看这里

| 遇到的情况 | 可以先这样处理 |
| --- | --- |
| 烧录后没有桌面 | 确认使用本产品固件并按 RESET；合并 BIN 地址应为 0x0，详见[烧录说明](../../firmware/README_ZH.md) |
| 画面太暗 | Settings 调高 Brightness，并检查供电 |
| 不知道怎么退出颜色循环 | 快速连续点击屏幕两下 |
| Touch Test 工具栏不见了 | 点顶部 Exit 返回，再重新打开应用 |
| 手机连设备热点后提示不能上网 | 保持连接，本地配网和图片上传不依赖互联网 |
| 192.168.4.1 打不开 | 板子保持配置/上传页面，手机连接设备热点；输入 HTTP 地址，不是 HTTPS 或搜索关键词 |
| 点击 Wi-Fi 名称不能连接 | Wi-Fi scan 只扫描，改用 Wi-Fi setup 网页填写密码 |
| 连接成功但保存失败 | 重启前重新提交配网，等待 Connected and saved；仅连接成功不代表下次自动连接 |
| 连 Wi-Fi 后还是旧日期 | 检查网络是否能上网并等待 NTP，首次对时可能需要 1～2 分钟 |
| 关闭 Wi-Fi 后仍显示北京时间 | 正常，系统和已校准的 RTC 继续走时，不自动切回旧日期 |
| 重新上电又变成初始日期 | 检查 RTC 是否保持供电，再联网校时；RTC 完全失去供电后不能保证保留日历 |
| 徽章首次打开一直准备中 | 等待存储初始化完成，不要反复重启或断电 |
| 徽章上传失败或网页无响应 | 保持热点连接，重新打开 Manage images，用 JPG/PNG/WebP 再试；先点 Refresh 确认是否已保存 |
| 徽章裁剪不合适 | 上传前调整预览位置和 Zoom，再保存覆盖所选位置 |
| 徽章与原图颜色不完全一致 | 颜色量化所致，以网页保存前的预览为参考 |
| SD card 显示 Unavailable | 未插卡时正常；已插卡则检查接触和 FAT32 格式，再点 Refresh |
| GravityBall 一直校准 | 平放并保持静止，移动中校准会重新开始 |
| PinsTest 显示 -- | 本轮尚未设置，点击对应引脚后才显示 H 或 L |

## 7. 自行编译和重新烧录

日常体验可以直接使用[出厂合并固件](../../firmware/README_ZH.md)，无需安装开发环境。本目录是出厂源码，使用 **ESP-IDF v5.5.4、LVGL v9.5.0**；开发板配置为 **ESP32-C6、16 MB Flash、无 PSRAM**。

按 [ESP-IDF 入门指南](../../docs/getting-started-idf_ZH.md)安装环境，在本目录打开 ESP-IDF 终端，执行：

```sh
idf.py set-target esp32c6
idf.py build
idf.py flash monitor
```

首次构建会下载托管组件，需要电脑联网。`Ctrl+]` 退出串口监视器。修改天气城市时，运行 `idf.py menuconfig`，在 **C6 2.73 Weather** 中修改省份、城市和显示名称，再重新编译、烧录。

合并 BIN 按[出厂固件说明](../../firmware/README_ZH.md)在 **0x0** 烧录，参数为 **ESP32-C6 / DIO / 80 MHz / 16 MB**。单独应用 BIN 不是合并固件，不要直接写到 0x0；从源码烧录使用 `idf.py flash`。

全片擦除或覆盖相应数据分区会清除已保存的 Wi-Fi、亮度和徽章图片，需要重新设置与上传；SD 卡文件不受 Flash 擦除影响。
