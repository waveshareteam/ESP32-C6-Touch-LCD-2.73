# QMI8658 惯性传感器

[English](README.md) | [简体中文](README_ZH.md)

## 功能说明

读取板载 QMI8658 的三轴加速度和角速度。

## 硬件准备

ESP32-C6-Touch-LCD-2.73。开发板和 USB 数据线。

## 运行方法

1. 按照 [Arduino 入门指南](../../../../docs/getting-started-arduino_ZH.md)配置环境，打开 `02_I2C_qmi8658.ino`。
2. 选择 **ESP32C6 Dev Module** 并上传，打开 **115200 波特率**串口监视器，再按 RESET。
3. 转动或倾斜开发板，观察串口数值。

## 预期现象

串口约每秒更新一次，加速度单位为 m/s²，角速度单位为 rad/s。本例不初始化液晶。

## 常见问题

初始化失败时请复位并检查 I²C 连接。静止时，加速度三轴合成值约为 9.807 m/s²，包含重力分量。

引脚定义请参阅[板级 IO 指南](../../../../docs/board-io_ZH.md)。
