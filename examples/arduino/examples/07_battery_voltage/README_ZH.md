# 电池电压

[English](README.md) | [简体中文](README_ZH.md)

## 功能说明

在液晶和串口显示电池 ADC 原始读数及换算电压。

## 硬件准备

ESP32-C6-Touch-LCD-2.73。开发板和 USB 数据线；测试电池电压时请接入规格匹配的电池。

## 运行方法

1. 按照 [Arduino 入门指南](../../../../docs/getting-started-arduino_ZH.md)配置环境，打开 `07_battery_voltage.ino`。
2. 选择 **ESP32C6 Dev Module** 并上传，打开 **115200 波特率**串口监视器，再按 RESET。
3. 观察电压和 ADC 数值，并与电池端子处的万用表读数比较。

## 预期现象

约每秒刷新一次，12 位 ADC 范围为 0–4095；电压 = ADC × 3.3 / 4095 × 3。每次取 8 个样本平均。

## 常见问题

这是电压测试，并非电量计或标定后的百分比。仅接 USB 的读数不能确认电池是否存在或剩余电量；参考电压和分压电阻误差会影响精度。

引脚定义请参阅[板级 IO 指南](../../../../docs/board-io_ZH.md)。
